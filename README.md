## 📌 Sobre o Projeto

O **Cidadan.ia** é uma iniciativa desenvolvida por estudantes universitários com o objetivo de simplificar e democratizar o entendimento de direitos legais para o cidadão comum. Utilizando Inteligência Artificial, a plataforma oferece assistência rápida e acessível para tirar dúvidas jurídicas cotidianas.

O projeto teve início em **2024**, na cidade de Teresina (PI), como parte de uma iniciativa acadêmica no **iCEV**.

---

## 🚀 Funcionalidades

- **🤖 Assistente Legal (IA):** Interface de chat interativa para consulta de dúvidas sobre direitos e leis brasileiras.
- **📱 Design Responsivo:** Interface otimizada para desktops, tablets e smartphones.
- **📄 Navegação Fluida:** Páginas estruturadas para informações do projeto (*Sobre Nós*) e contato (*Contato*).

---

## 🛠️ Tecnologias e Ferramentas Utilizadas

- **HTML5 & CSS3** — Estruturação e estilização visual.
- **JavaScript (ES6+)** — Manipulação do DOM e lógica de navegação.
- **Chatbase** — Plataforma e motor de Inteligência Artificial para criação e hospedagem do chatbot.
- **Google Material Symbols & Ionicons** — Iconografia da interface.
